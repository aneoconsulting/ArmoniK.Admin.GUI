ArmoniK.Admin.GUI documentation
===============================

The ArmoniK Admin GUI is a tool to operate, monitor and manage an
`ArmoniK <https://aneoconsulting.github.io/ArmoniK>`_ cluster. It can be
deployed during the cluster creation and is accessible in the browser at the
cluster address.

Head to the :doc:`Getting Started <content/1.getting-started>` guide to begin.

.. warning::

   The documentation is being updated to the upcoming version of ArmoniK Admin
   GUI (``0.12``). There may be mistakes. If you find one, please open an issue
   on `ArmoniK.Admin.GUI <https://github.com/aneoconsulting/ArmoniK.Admin.GUI/issues>`_
   or wait.
